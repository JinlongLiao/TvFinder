## 本地库源码

本项目随仓库提供 [FatFs R0.16](https://elm-chan.org/fsw/ff/) 的 `ff.c`、`ff.h`、`ffunicode.c`、`diskio.h`。作者 ChaN；原始许可见 [`app/src/main/cpp/fatfs/LICENSE.txt`](../app/src/main/cpp/fatfs/LICENSE.txt)，要求源码再分发保留版权声明、许可条件和免责声明。`ff.c` 合入上游 [patch-1 与 patch-2](https://elm-chan.org/fsw/ff/patches.html)；`ffconf.h` 是本项目配置，`usb_fatfs_bridge.c` 是本项目编写的 Android 适配层。构建时这些 C 文件由 NDK/CMake 编译为 `libtvfinder_fatfs.so`，不额外下载 C 源码。详见[本地库编译指南](本地库编译指南.md)。
