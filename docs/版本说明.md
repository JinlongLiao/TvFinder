# 版本说明

## 开发中 · 2026-09-24 · 尚未重新发布 Release APK

- 源码构建版新增应用内音视频播放、PDF 逐页预览、纯文本与 Markdown 查看、HTML 预览；电视解码器不支持的媒体仍可选择其他应用。
- USB 直连文件在应用内按需读取；交给外部应用时先复制到应用临时缓存。未知格式也可尝试系统应用选择器。
- HTML 允许脚本和在线资源；本地资源限定在同目录及子目录。电视实机播放与 USB 大文件兼容性仍待验收。

## 0.1.0 · 2026-09-22 · 预览版

作者：liaojinlong。项目：https://github.com/JinlongLiao/TvFinder

### 新增

- 面向电视遥控器的侧栏导航、四列文件网格、清晰焦点及原创电视文件夹 Logo。
- 电视内部共享存储和 USB 容量展示、文件浏览与调用外部应用打开。
- 复制、移动、重命名、永久删除、新建文件夹；操作进度及取消请求。
- 浅色、深色、跟随系统三种主题，默认浅色；持久保存选择，切换保留目录与待粘贴项。
- 中英文界面、应用内语言选择、设备信息、关于、离线版本说明与许可声明。
- 安装包、Office 文档、PDF、文本、音视频、图片、归档、代码、字幕、电子书和磁盘镜像图标。
- 默认存储首页保持不变，侧栏可进入系统根目录 `/`；目录页提供大号可聚焦面包屑，可直接跳转到任意祖先目录。

### 文件保护

- 同名目标拒绝覆盖，禁止路径穿越与递归复制到自身。
- 移动在复制和内容校验后删除源；失败会说明源与目标保留状态。
- 删除确认默认聚焦“取消”；从网格切换到工具栏仍保留文件选择。
- 复制取消包含最后一个数据块完成时的取消检查。

### 兼容性与已知限制

- 最低 Android 11 / API 30；包名 io.github.jnlongliao.tv.finder。
- 当前 Release APK 使用独立发布密钥签名；功能仍处于 0.1.0 预览阶段，尚未完成应用商店发布验收。旧的 debug APK 与当前包签名不同。
- 当前海信电视报告系统型号 `VIDAA_TV`、设备代号 `MT9653`、Android 11 / API 30；E5Q 为用户提供的系列名称，具体商品型号未由系统确认。完整 UI、NTFS、断电和大文件场景仍需验收。
- 不会自动成为默认系统文件管理器；不包含系统入口接管、NAS/SMB、回收站、播放器或 APK 安装器。
- 显示某类文件图标不代表支持直接运行或播放该格式。
- 不支持跨应用并发修改同一文件；删除和移动的源删除阶段不具备事务回滚能力。
