- JDK 17 / SDK 34 构建成功：`gradlew.bat assembleDebug testDebugUnitTest lintDebug`。
- 33 项单元测试通过：文件操作 13 项、类型识别 6 项、主题配置 4 项、权限与系统根目录导航 10 项。
- Lint：0 错误、8 警告。警告涉及 target SDK / 依赖更新提示、备份规则、自适应图标资源目录与闲置资源、容量 API 建议及启动图标 monochrome；未隐藏或建立基线跳过。

## 模拟器操作验证

环境为 Android 14 x86_64 通用模拟器，横屏并通过 ADB 注入方向键、确定、返回和菜单键；不等同于海信电视固件。

- 首次使用默认浅色，即使系统已处于深色；手动深色在进程重启后保留。
- 固定浅色/深色不受系统变化影响；跟随系统能够在页面打开时响应明暗切换。
- 单独选择中文后，跟随系统仍能响应；切换主题保留当前目录和待粘贴项。
- 复制、移动、重命名、新建文件夹、永久删除和默认聚焦取消通过；文件内容逐字节比对，源与目标状态符合操作语义。
- 移动 1 GiB 测试文件时触发系统主题变化，任务未被取消；目标长度与 SHA-256 一致，源文件已删除，任务后界面为深色。
- 1920×1080 / 320 dpi 与 1280×720 / 213 dpi 截图检查通过，侧栏设置可见，网格焦点清晰；完整目录通过滚动浏览。
- 中英文关于页、版本说明、Apache-2.0 和第三方声明已在模拟器中打开验证。

## 未验证与边界

海信 E5Q 真机、Android 11 实机、USB 热插拔、NTFS/exFAT 读写、断电及厂商默认入口尚未验收。文件系统访问依赖电视驱动及挂载权限，应用未内置 NTFS/exFAT 驱动，也不会自动接管系统文件管理器。截图中的各类文件为图标测试样本，不代表格式播放或运行能力。

截图见本目录的“首页-浅色.png”“首页-深色.png”“主题设置.png”“文件浏览-1080p.png”“文件浏览-720p.png”。安装包校验值见 SHA256SUMS.txt。

## English validation notes

Build, 33 unit tests, XML/resource parity, encoding checks, and APK v2 signature verification passed. Lint reports 0 errors and 8 warnings; these warnings were not suppressed. This is a debug-signed 0.1.0 preview APK.

Android 14 emulator checks covered Light as the initial default, persisted Dark selection, live System mode changes, explicit Chinese combined with System mode, folder/clipboard restoration, and basic file operations. A system-theme change during a 1 GiB move did not cancel the task: destination size and SHA-256 matched, the source was removed, and Dark was applied afterwards. Layouts were visually checked at 1080p / 320 dpi and 720p / 213 dpi.

This was a generic landscape Android emulator, not Hisense E5Q firmware. Real-TV behavior, Android 11 hardware, USB hotplug, NTFS/exFAT write access, power loss, and vendor default-app integration remain unverified. Filesystem support depends on TV drivers and permissions; no NTFS/exFAT driver is bundled. Sample file icons do not prove playback or execution support.
