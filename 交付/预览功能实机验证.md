# 预览功能实机验证

日期：2026-09-24。源码版本：0.1.0 本地 Debug 更新。包名：`io.github.jnlongliao.tv.finder`。

## 功能与按键

从文件列表按确定键进入应用内预览；预览页上/下键切换同目录前后可预览文件，不循环。左/右键按当前类型执行 PDF 翻页、Office/文本翻可视屏或音视频后退/前进 10 秒。菜单键打开系统外部应用选择器，返回键回到原文件列表。外部应用是否出现由电视已安装应用和固件解析结果决定。

应用内 Office 仅提取 `docx/docm`、`xlsx/xlsm`、`pptx/pptm/ppsx` 的有限纯文字，不还原排版、公式、样式或嵌入媒体。传统 `doc/xls/ppt` 未实现内建解析。普通文本按 UTF-8 读取，最多展示前 1 MiB；USB 直连预览每个临时副本最多 1 GiB。媒体播放依赖电视自身 Android 解码器。

## 设备与测试文件

- 海信电视报告型号 `VIDAA_TV`、设备代号 `MT9653`，Android 11 / API 30；无线 ADB 已配对。
- 内置共享存储测试目录：`/storage/emulated/0/Download/TVFinderPreviewTest`。含 120 行 DOCX、35 秒 MP3、35 秒 MP4、两页 PDF、PNG 和 TXT 等专用样本。
- USB：侧栏显示的 `aigo MiniKing`，由应用 USB Host/FAT/exFAT 直连路径访问。测试 MP3 与 MP4 通过“从电视导入”加入 U 盘根目录，验收后均已删除并复查不存在。

| 场景 | 实际结果 |

| 内置存储连续浏览 | 在同一预览页按下键依次经过 DOCX、MP3、MP4、另一 DOCX、另一 MP4、PDF、PNG、TXT；无需逐个退出重开。 |
| PDF 遥控器翻页 | 两页样本按右键显示第 2 / 2 页；纸张为白底、正文可见。 |

| USB 相邻文件 | 从导入的 `preview-seek.mp3` 预览按下键，直接切换到导入的 `preview-seek.mp4` 并播放；退出后两份测试文件均从 U 盘清理。 |
| 外部应用入口 | 菜单键可打开外部应用选择器；测试 MP4 曾在电视自带兼容应用中显示缩略画面。外部应用完整播放与 Office/WPS 行为未据此宣称通过。 |
